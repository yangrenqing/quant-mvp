# 产品设计文档

## 1. 产品定位

`quant-mvp` 是一套面向个人研究和半自动投研的量化分析系统。  
它当前不是实盘交易终端，而是一个围绕以下目标构建的投研平台：

- 统一获取 A 股和美股基础行情
- 生成每日交易计划和候选池
- 对单票、批量、组合进行回测
- 持续沉淀报告、实验记录、模型版本和历史快照
- 支持从规则策略逐步升级到数据驱动评分

核心设计原则：

- 先做可验证，再做复杂
- 先保证历史留痕，再做自动学习
- 先让日报和组合链路稳定，再提升 alpha

## 2. 目标用户

当前主要面向：

- 个人投资者
- 独立量化研究者
- 需要快速验证策略思路的开发者

不直接面向：

- 高频交易
- 多人协作的机构级 OMS / EMS
- 实盘自动下单系统

## 3. 产品目标

当前阶段目标：

- 每天稳定生成可读的选股和组合报告
- 让策略、模型、实验都有历史记录
- 让参数调整、回测和模型训练进入可复现流程

下一阶段目标：

- 提升组合质量和策略收益/超额
- 增强回测真实性
- 建立稳定研究工作流

## 4. 核心功能

### 4.1 行情与数据

- 按标的自动选择数据源
- A 股优先走 Tushare / BaoStock
- 美股优先走 Alpha Vantage
- 支持本地 CSV 回退
- 支持本地缓存和诊断记录

### 4.2 每日计划

- 生成单标的计划报告
- 输出 `BUY / SELL / HOLD / SKIP`
- 明确模式、市场日期、原因和次日计划

### 4.3 A 股扫描

- 扫描本地股票池
- 按 `建议关注 / 观望 / 回避` 分层
- 输出 focus 列表
- 支持 JSON / HTML / TXT 报告

### 4.4 回测体系

- 单票回测
- 批量回测
- 组合回测
- 网格搜索
- 成本、滑点、基准、回撤、超额等指标

### 4.5 模型与学习

- 导出训练样本
- 训练线性因子模型
- 滚动验证
- 模型版本归档
- 自动比较候选模型和当前模型

### 4.6 持久化与归档

- SQLite 记录运行历史、实验历史、dashboard 快照、模拟账户台账
- `reports/history/YYYY-MM-DD/...` 保留日报快照
- `reports/run_index.jsonl` 统一索引

## 5. 用户工作流

### 5.1 日常使用

1. 运行 `bash scripts/daily_run.sh`
2. 查看 `dashboard.html`
3. 查看 `a_share_focus.html`
4. 查看 `portfolio_backtest.html`
5. 根据需要看 `history_compare.html`

### 5.2 研究使用

1. 运行扫描和组合回测
2. 导出数据集
3. 训练模型
4. 记录实验结果
5. 对比不同参数和不同模型版本

## 6. 关键页面

- `dashboard.html`
  日常总览页
- `history_compare.html`
  历史运行对比页
- `market_overview.html`
  多市场汇总页
- `portfolio_backtest.html`
  组合表现页

## 7. 当前边界

当前系统仍有这些边界：

- 不是自动下单系统
- 数据源稳定性受第三方接口影响
- 模型能力还处于基础阶段
- 超额收益能力仍需继续优化

## 8. 后续方向

优先级最高的后续方向：

- 进一步提高回测真实性
- 强化组合构建逻辑
- 继续提升 A 股策略质量
- 引入更适合 A 股的研究成果和因子
